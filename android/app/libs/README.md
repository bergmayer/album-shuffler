The real app uses Apple's MusicKit SDK for Android 1.1.2:

- `musickitauth-release-1.1.2.aar`
- `mediaplayback-release-1.1.1.aar`

Download it from [Apple Developer](https://developer.apple.com/download/all/?q=Android%20MusicKit), then run `python3 tools/install_musickit.py /path/to/Android-MusicKit-SDK-1.1.2` from `android/`.

The vendor binaries are kept out of Git. Follow Apple's SDK license when distributing an application built with them.
